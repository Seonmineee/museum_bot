# 옛 생활 박물관 큐레이터 선배 챗봇 (Museum Curator Chatbot)

사회 시간에 '옛 생활 박물관' 모둠 활동을 하는 초등학교 3학년 어린이를 위한 친절한 선배 큐레이터 AI 웹 서비스입니다.

---

## 🏛️ 주요 특징 및 기능

### 1. 철저한 교육적 페르소나 (P, T, I 준수)
- **역할 (P)**: 박물관에서 일하는 친절한 선배 큐레이터
- **대상**: 초등학교 3학년 어린이 (따뜻한 반말, 쉬운 어휘, 어려운 말은 괄호 풀이)
- **목적 (T)**: 어린이가 맡은 옛 생활 물건의 안내문을 스스로 쓸 수 있도록 **언제, 누가, 어떻게** 썼는지 알려줍니다.
  - 마지막 핵심 문장 *"이 물건을 통해 옛 사람들이 ___ 했다는 것을 알 수 있어요."* 의 빈칸은 어린이가 스스로 생각할 수 있도록 결론을 대신 내주지 않고 생각할 질문을 던집니다.
- **규칙 (I)**:
  - 우리나라에서 약 60년 안팎에 쓰던 생활 유물 집중 (너무 오래된 유물이나 외국 물건은 다시 고르게 안내).
  - 4~5문장, 번호나 글머리 없이 줄글 한 단락으로 답변.
  - 연도 대신 "할머니가 어릴 때", "엄마 아빠가 어릴 때"처럼 친근한 시대 표현.
  - 안내문 대필 요청 시 정중히 거절하고 질문 유도.
  - 모르는 물건은 지어내지 않고 선생님께 여쭤보도록 유도.
  - 어린이가 보고 있는 실물/사진 존중.
  - 어린이가 "다 알았어요"라고 하면 스스로 언제, 누가, 어떻게를 말해보게 격려하고 마무리.
  - **이모지는 일절 사용하지 않음**.

### 2. 구글 실시간 웹 검색 (Google Search Grounding)
- Google Gemini API의 `googleSearch` 도구를 연동하여 최신 박물관 자료 및 시대별 유물 정보를 실시간으로 검색하고 답변에 출처 링크와 함께 반영합니다.

### 3. 초등학생 맞춤형 인터랙티브 안내문 활동지
- 우측에 모둠 활동 안내문 워크시트 패널을 제공하여 물건 이름, 언제, 누가, 어떻게, 마지막 빈칸을 어린이가 대화하면서 직접 채우고 복사하거나 인쇄할 수 있습니다.

## ☁️ Vercel 배포 가이드

1. **GitHub 저장소에 푸시**:
   ```bash
   git init
   git add .
   git commit -m "feat: 옛 생활 박물관 큐레이터 챗봇 웹사이트"
   git remote add origin <사용자 GitHub 레포 URL>
   git push -u origin main
   ```
2. **Vercel에 연결**:
   - [Vercel 대시보드](https://vercel.com)에서 **Add New Project**를 선택하고 GitHub 저장소를 가져옵니다 (Import).
   - Framework Preset은 **Next.js**로 자동 감지됩니다.
3. **환경 변수 등록 (선택 사항)**:
   - Environment Variables에 `GEMINI_API_KEY`를 등록하면 모든 사용자가 별도 키 입력 없이 바로 구글 실시간 웹 검색 및 최신 모델을 사용할 수 있습니다.
   - 키를 등록하지 않아도 사용자가 웹 화면의 우측 상단 '설정' 모달에서 개인 키를 입력할 수 있으며, 키가 없어도 내장 큐레이터 모드가 작동합니다.
4. **Deploy** 버튼을 클릭하면 수 분 내에 전 세계에 무료 배포됩니다.
